# 角色图片中转站

按作品整理角色图片，供「小说自动生成器」批量写卡时导入酒馆使用。本仓库只做收集和中转；酒馆侧的导入与送图尚未开发。

## 目录

一部作品一个文件夹，清单、图片都在里面，下载一个文件夹即可：

```text
images/原神/
  00-清单.md      任务名单和目录（请保持这个文件名，打开文件夹时会排在最前）
  温迪.jpg        以中文角色名命名的图片
images/星穹铁道/  以后可按同样方式增加作品
examples/作品模板/00-清单.md
```

`00-清单.md` 是唯一数据。勾选表示图片已收集；角色名是指向图片的相对链接，例如 `- [x] [温迪](温迪.jpg)`。其他称呼可写在后面：`- [x] [雷电将军](雷电将军.jpg) 别名：雷电影、影`。`别名：` 和 `别名:` 都可以，多个别名用顿号、逗号或斜杠分隔。行尾其他备注在检查图片时会忽略。

## 收集一张图

1. 找到一张能看清该角色整体外形和模样的图片。画面上有文字也可以，只要人物可辨认。
2. 保存为 `images/<作品>/<角色名>.jpg`、`.png` 或 `.webp`，大小 500 KB 至 2 MB（按 500,000 至 2,000,000 字节计算）。
3. 在该作品的 `00-清单.md` 中勾选对应角色，并把名字链接到这个文件；如有需要再加上别名。
4. 提交到本仓库。不必手动运行检查脚本；CI 会自动检查已勾选项：文件是否存在、是否在本文件夹内、扩展名与文件头是否相符、大小是否在范围内。同一作品里别名或名称冲突时会给出警告。

## 添加新作品

在 `images/` 下新建文件夹，名称使用作品的常用中文名，例如 `images/星穹铁道/` 或 `images/崩坏3/`。复制 [examples/作品模板/00-清单.md](examples/作品模板/00-清单.md) 到新目录，保持文件名为 `00-清单.md`，再按上面四步收集图片。

## 下载单个作品

不必下载整个仓库。打开作品文件夹后，可用 [download-directory](https://download-directory.github.io/?url=https://github.com/cjhkcjgk3-sys/character-image-staging/tree/main/images/%E5%8E%9F%E7%A5%9E) 只打包 `images/原神/`；其他作品把链接里的路径换成对应文件夹即可。若已克隆仓库，也可以只压缩该目录：

```sh
zip -r 原神.zip images/原神
```

建议等该作品清单全部勾选后再打包下载。

## 以后怎么用

小说自动生成器将导入下载好的作品文件夹或压缩包，读取已勾选的条目，在批量写卡时一边替换名字、一边把对应图片发给模型。匹配前先规范化名字：去掉首尾空白，统一全角与半角，去掉空格和间隔点，并去掉作品前缀或后缀。因此 `原神·温迪`、`原神-温迪`、`温迪（原神）`、`温迪(原神)`、`【原神】温迪` 都视为 `温迪`。先与链接文本、别名、图片文件名（不含扩展名）比较；仍没有结果时，若某一条能唯一地互相包含，也可以匹配。没有结果或有多条可能时，提示缺少图片，只写卡不附图。该规则已在 `tools/check.py` 的 `normalize_name` 与 `match_name` 中实现，以后可直接移植。查找、导入和送图都尚未实现。

## 模型说明

当前按酒馆的 Chat Completion 来配置，使用两个来源：

- **Google Vertex AI**：可发送图片，请开启「发送内嵌媒体 / Send inline images」，并开启「启用网页搜索」。Gemini 在启用函数调用（function calling / tools）时会跳过网页搜索，因此这条流程请关闭函数调用。
- **自定义 OpenAI 兼容接口**：酒馆默认把自定义来源当作支持识图，开启「发送内嵌媒体 / Send inline images」后会发送图片。自定义来源没有酒馆自带的网页搜索开关；能否搜索取决于中转或模型本身（尚未核实）。若中转不提供搜索，就依靠图片和模型已有知识。

当前原神样本中，温迪、钟离、雷电将军、纳西妲、玛薇卡、安娜丝塔夏已勾选。芙宁娜、芙卡洛斯因小于 500 KB，保持未勾选，需更换更大的图片。
