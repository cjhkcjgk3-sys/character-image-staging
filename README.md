# 角色图片中转站

按作品整理角色图片，供「小说自动生成器」批量写卡时导入酒馆，并把图片本身交给当前模型。本仓库只做收集和中转；酒馆侧的本地导入与送图尚未开发。

## 使用流程

1. 在 `images/<作品>/00-清单.md` 列出要收集的角色。这既是任务名单，也是目录：文件名以 `00-` 开头，在 GitHub 打开该文件夹时会排在最前。
2. 为角色准备图片，用角色名作为指向图片的相对链接。勾选表示已收集，可直接使用；未勾选表示尚未收集或文件不合格，一眼能看出进度。
3. 运行 `python3 tools/validate_catalog.py images/<作品>`，由清单生成同目录的 `catalog.json`。
4. 名单全部勾选后，再按下方方式单独下载该作品文件夹。

后续还可增加 `images/星穹铁道/`、`images/崩坏3/` 等目录，每个作品文件夹自包含：清单、机器清单和图片都在其中，下载一个文件夹即可。

## 目录

```text
images/原神/               一部作品一个文件夹
  00-清单.md               任务名单和目录（请保持这个文件名）
  catalog.json             由清单生成的机器记录
  温迪.jpg                 以中文角色名命名的图片
docs/                      方案、清单约定和图片规则
examples/作品模板/         新增作品时的清单模板
tools/validate_catalog.py  生成并检查各作品的机器清单
```

根目录不再放置总清单。添加新作品时，复制 [examples/作品模板/00-清单.md](examples/作品模板/00-清单.md)，按 [添加新作品](docs/add-work.md) 操作。

名单中的角色名是 `角色名`，作品名来自文件夹；机器清单里的 `roster_name` 记为 `角色名（作品）`，例如 `温迪（原神）`。酒馆侧以后查找时，再兼容 `原神·温迪`、`温迪（原神）` 等写法。

## 下载单个作品

不必下载整个仓库。打开作品文件夹后，可用 [download-directory](https://download-directory.github.io/?url=https://github.com/cjhkcjgk3-sys/character-image-staging/tree/main/images/%E5%8E%9F%E7%A5%9E) 只打包 `images/原神/`；其他作品把链接里的路径换成对应文件夹即可。若已克隆仓库，也可以只压缩该目录：

```sh
zip -r 原神.zip images/原神
```

建议等该作品清单全部勾选后再打包下载。

## 图片要求

- 以角色为主体，能看清整体外形和模样即可，不必追求材质或背景细节；画面上有文字也可以，只要人物仍可辨认。
- 单张大小建议在 500 KB 至 2 MB 之间（按 500,000 至 2,000,000 字节计算）。
- 默认按作品建一层目录，图片用中文角色名；其他版本用括号注明，例如 `角色甲（演出服）.webp`。

当前原神样本中，温迪、钟离、雷电将军、纳西妲、玛薇卡、安娜丝塔夏六张已勾选。芙宁娜为 487,808 字节，略低于 500 KB；芙卡洛斯约 120 KB。这两张仍留在目录中，但保持未勾选，需要更换更大的图片后再勾选。

## 检查

需要 Python 3.9 或更高版本，只需标准库：

```sh
python3 -m unittest discover -s tests -v
python3 tools/validate_catalog.py images/原神
python3 tools/validate_catalog.py --check --all
```

前两条分别运行测试、根据清单更新机器记录；`--check` 只检查不写入，供 CI 使用。路径相对于作品文件夹，也可用来检查已单独解压出来的作品目录。未勾选项会给出警告，不会使检查失败。
