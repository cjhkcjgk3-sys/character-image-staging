# 作品名角色图片清单

复制本文件夹的结构，在 `images/` 下新建作品目录，例如 `images/星穹铁道/` 或 `images/崩坏3/`。把本文件放到新目录并改成实际角色名单。文件名保持 `00-清单.md`，这样在 GitHub 打开文件夹时清单会排在最前。

勾选表示图片已收集；未勾选表示尚未收集或文件不合格。有图片时，把角色名写成指向该文件的相对链接。版本写在角色名后的括号里。行尾括号是备注；以「失败」开头的备注表示收集失败。

写好名单后，在仓库根目录运行：

```sh
python3 tools/validate_catalog.py images/作品名
```

这会生成同目录下的 `catalog.json`。不要手写机器清单。
