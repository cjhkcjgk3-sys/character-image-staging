## 图片处理

源 PNG 先按二进制下载，核对上游文件大小，并用 Pillow 完整解码。画布外完全透明的边缘可安全裁掉；源图低于 1,000,000 字节时保留原 PNG。超限图片转 WebP，优先保留细节；大图一般将最长边收至 1,800 像素后从高质量档尝试。首轮有 8 张需要低于 q90 才能压进上限，于是改用 1,450–1,600 像素版本，质量提高到 q92–94。最终没有图片低于 q90。

324 张全部小于 1,000,000 字节，范围 290,276–998,390 字节，总计 259.24 MiB。15 张符合上限的 PNG 保留原格式，其余转为 WebP；输出文件长边 940–1,800 像素。

## 可复用经验

角色 ID 数据表适合做批量精确映射，最终文件名仍用清单角色名。优先选实际存在的高分辨率基础立绘；文件名带 `_b` 的替代版本是低分辨率文件，只有高分辨率版本缺失时才考虑。Arknights 的透明特效容易触发矩形空洞规则，不能直接按自动告警取消图片；需结合洋红底联系表检查人物本身是否完整。
