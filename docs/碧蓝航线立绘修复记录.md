### 根因与有效处理方法

- 多张旧图与上游 AzurLane-AssetDownloader 图片仓库中的对应文件逐字节相同。它们能正常解码、大小也合规，但上游所选变体本身就有透明缺口、错乱内容或只有背景／场景。因此这批问题不是下载截断；继续重复下载相同 URL 不会修好。
- 对可解码图片，文件头、CRC、大小、Pillow 完整解码都不能判断人物有没有缺脸。确认内容问题需要查看缩略图并点开原图；如果是来源版本本身有问题，改找 BWiki 对应角色的完整立绘或同形态官方海报。
- 多次查询 BWiki `api.php` 的页面图片列表时遇到 HTTP 567。知道文件标题后，用 `https://wiki.biligame.com/blhx/Special:Redirect/file/<文件名>` 配合浏览器 User-Agent 和对应角色页 Referer 获取原图，27 张候选全部下载成功；以后应先少量试取，缓存标题和直链，限并发下载并对失败项重试。
- 图片按二进制保存。Wiki 原图超过仓库限制时，保留原始分辨率，用 Pillow WebP `quality=98`、`method=6` 编码；本次所有替换图均低于 1,000,000 字节，不设最低体积，没有使用生成式补画或模糊修复。
- `小海伦娜.png`、`旗风.png` 改为简体中文名的 `.webp` 文件，并同步更新清单链接；其余沿用原中文文件名。
